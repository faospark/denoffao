SuiSaveEditor: Suikoden II HD Save Architecture.

SuiSaveEditor is a minimal, static web-based GUI and Progressive Web Application (PWA) crafted specifically for editing decrypted Suikoden II HD Remaster JSON save files produced by SuikodenFix. Designed with a clean, responsive interface, it gives players granular control over party formations, combat stats, smart rune restrictions, inventories, and castle progression—with zero installation and 100% client-side privacy.

Why SuiSaveEditor?

Traditional save editors often require heavy desktop runtime dependencies (.NET runtimes, Python interpreters, or Java environments) and carry risks when executing third-party executables. SuiSaveEditor takes a modern, web-first approach:

100% Client-Side

Absolute Privacy

Your save files never leave your computer. All JSON parsing, data manipulation, validation, and serialization occur directly within your web browser's local memory using vanilla JavaScript.

Zero Install

Instant Cross-Platform

Runs seamlessly on Windows, macOS, Linux, and the Steam Deck browser without installing extra software or command-line scripts. Just open the URL and load your save.

Smart Logic

Safety & Filtering

Built-in data dictionaries and validation protect against invalid rune slots, corrupted character arrays, and incorrect item IDs, helping prevent softlocks or crashes.

Requirements & Save Decryption

The official PC release of Suikoden I & II HD Remaster stores save files in an encrypted binary format. To inspect and edit these values with SuiSaveEditor, you need the save file in human-readable JSON format.

Critical Save Precautions:
  • Always create a manual backup of your original save files before opening or saving with any editor.
  • Turn off Steam Cloud saving for Suikoden I & II HD Remaster temporarily while editing saves to avoid Steam Cloud overwriting your changes.
Method 1 (Recommended)

SuikodenFix

Enable the save editing feature in SuikodenFix. When running the game, SuikodenFix automatically outputs a decrypted JSON save into the game root directory or into (GAME_PATH)\SuikodenFix\Backup\gsd2\.

Method 2

SuikodenSaveDecrypter

Use SuikodenSaveDecrypter by d3xMachina to manually decrypt your raw binary save file into JSON before loading it into SuiSaveEditor.

Step-by-Step Workflow

Editing your decrypted save takes less than a minute from start to finish:

1

Generate or Decrypt Your Save File

Ensure the save edit feature is turned on in SuikodenFix. When you save or boot Suikoden II Remaster, a JSON representation of your save is placed in (GAME_PATH)\SuikodenFix\Backup\gsd2\ (or the root folder). Copy this JSON file to a safe work location.

2

Open SuiSaveEditor in Browser

Navigate to faospark.github.io/suisaveeditor/ on your PC, Steam Deck, or tablet.

3

Load JSON File & Verify Slot

Click Choose File and select your .json save. SuiSaveEditor immediately parses the file, displaying an active save file indicator badge and unlocking the editor navigation tabs.

4

Modify Desired Values

Navigate across the Active Party, Battle Characters, Inventories, and Castle tabs. Adjust stats, equip legendary runes, or add missing key items.

5

Export & Replace

Click the Save / Download JSON button. Place the updated JSON file back into the SuikodenFix backup directory and load your game. SuikodenFix will inject the modified values back into memory!

Offline PWA & Built-In Debug Features

SuiSaveEditor is built as a complete Progressive Web App with dedicated Service Worker caching:

Offline Ready

Full PWA Capabilities

After your first visit, the entire web application is cached locally via its service worker. You can use it completely offline on airplanes, commutes, or portable Steam Deck sessions without an active internet connection.

Dev Shortcut

Debug Mode (Ctrl+D)

Press Ctrl+D to toggle Debug Mode, which automatically loads built-in sample save files for testing without having an actual save file handy. The toggle state persists across browser sessions.

Status Bar

Visual Status Indicators

The status bar header provides instant visual feedback: green indicates Debug Mode is active, orange shows Offline PWA Mode, and purple denotes combined states.
