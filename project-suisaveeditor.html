Why Native Rust? — A Note from the Author

A quick, honest explanation of why Bright Shield Save Editor moved toward a Native Rust desktop application instead of staying purely web-based:

From Web to Tauri

Hand-Built Foundation

Almost the entire Web Save Editor was built by hand — the game research, the save-structure mapping, the manual coding, and even picking the CSS framework. After accomplishing a lot with the web version, a Tauri desktop build was packaged to work around browser restrictions. While Tauri solved a few pain points, at the end of the day it is still the web editor wrapped in an executable.

Native Rust Port

Fast Native Software

With AI assistance, the editor was ported into a pure Native Rust application (BrightShield.exe). When you already know the domain and exactly what needs to be built, pairing Rust with AI assistance makes it possible to deliver fast, reliable native software with zero browser overhead, instant tab switching, and low memory usage.

What's Next

Reaching Maturity

As Bright Shield Save Editor gets close to feature saturation, the remaining major features simply aren't practical in a browser: built-in native save decryption & conversion (editing saves directly without needing SuikodenFix or an external decrypter first) and automatic game & save folder detection on Windows.

Requirements & Save Decryption

Bright Shield Save Editor currently edits decrypted JSON save files from Suikoden II HD Remaster generated by SuikodenFix or SuikodenSaveDecrypter.

Critical Save Precautions:
  • Turn off Steam Cloud saving for Suikoden I & II HD Remaster before editing saves to avoid Steam Cloud overwriting your changes.
  • Always keep a backup of your original save files (Bright Shield Native Rust also maintains immutable backups\*.bak snapshots, a Restore Diff Modal, and full .zip snapshots).
Method 1 (Recommended)

SuikodenFix

Enable the save editing feature in SuikodenFix. When running the game, SuikodenFix automatically outputs a decrypted JSON save into the game root directory or into (GAME_PATH)\SuikodenFix\Backup\gsd2\.

Method 2

SuikodenSaveDecrypter

Use SuikodenSaveDecrypter by d3xMachina to manually decrypt your raw binary save file into JSON before loading it into Bright Shield Save Editor.

Step-by-Step Workflow

Editing your decrypted save takes less than a minute from start to finish:

1

Generate or Decrypt Your Save File

Ensure the save edit feature is turned on in SuikodenFix (or decrypt via SuikodenSaveDecrypter). When you save or boot Suikoden II Remaster, a JSON representation of your save is placed in (GAME_PATH)\SuikodenFix\Backup\gsd2\ (or the root folder).

2

Launch Your Preferred Edition

Run BrightShield.exe from the Bright Shield Save Editor (Native Rust v2.1.0) download, launch the standalone Tauri Desktop Edition, or open the Web Save Editor Hub in your browser.

3

Select Save Slot & Automatic Backup

In Bright Shield (Native Rust), pick your save directly from the auto-scanned Saves home tab with portraits, search, and sort. A silent backup (backups\*.bak on desktop or localStorage snapshot on web) is created automatically.

4

Modify Party, Runes, Items & Castle

Navigate across the editor tabs to customize your 6-character squad, combat stats, visual MP squares, runes, Tessai's Hammers, S1 Transfer data, inventories, and 108 Stars recruitment flags.

5

Save Changes & Load In-Game

Save directly to your save directory (or use the Restore Diff Modal anytime to compare and roll back changes) and load your game in Suikoden II HD Remaster.
