Kupo-UI.PR: Pixel Remaster UI Architecture.

Kupo-UI.PR is a modern BepInEx IL2CPP runtime plugin designed specifically for the Final Fantasy Pixel Remaster series (FF1 through FF6). Built from the ground up to eradicate the tedious friction of unpacking, repacking, and editing duplicate Unity .bundle files, Kupo-UI.PR provides an end-to-end suite of 6 modular engines spanning hot-reloadable texture replacement, dynamic dialogue speaker portraits, data-driven GameObject layout manipulation, rich-text inline icons, and custom typography injection.

Background & Origins

KupoUI.PR grew out of the architectural development of the modern version of Darker UI for the Pixel Remasters. Historically, crafting user interface modifications for Final Fantasy I–VI PR was exceptionally grueling: artists and modders were forced to extract enormous Unity asset bundles, manually edit dozens of duplicate UI sprites scattered across disjointed asset files, repack the bundles, and pray that official game updates wouldn't invalidate their hard work.

After developing advanced IL2CPP runtime hooks for other game engines, author faospark applied those core breakthroughs to the Pixel Remaster series. What initially began as a simple tool to address specific menu contrast pain points quickly expanded into a complete runtime modding ecosystem. Its moniker, KupoUI.PR, is a respectful homage to the legendary Kupo UI mod for Final Fantasy IX.

Ecosystem Coexistence & Modding Synergy KupoUI.PR is explicitly not designed to replace community pillars like Magicite, Memoria, or FFPRFix. Each of these utilities solves distinct architectural challenges (e.g., audio, resolution, gameplay scripting). KupoUI.PR focuses laser-sharp on the UI/UX rendering layer, dynamic portraits, typography, and runtime hierarchy injection, and is designed to operate in harmonious tandem alongside them.
Known Incompatibilities to Keep in Mind
  • Memoria's Classic Text Box Framework: Not recommended. Both frameworks patch dialogue box presentation, but utilize fundamentally conflicting low-level hooking mechanics.
  • Legacy Speaker Tag Mods: Any mod that destructively restructures the dialogue message box to embed portraits will conflict with KupoUI.PR's built-in speaker portrait injector.

The 6 Core Architectural Engines

KupoUI.PR partitions UI responsibilities into six decoupled, high-performance runtime subsystems:

1. Texture & Theme Engine

Zero Bundles

Drop loose PNG or DDS files into categorized folders to replace frames, cursors, backgrounds, and button prompts on the fly.

  • 5-Layer Priority Pipeline: Cleanly isolates themes, frames, cursors, background tints, and button prompt overrides.
  • Path-Based Overrides: Disambiguates duplicate filenames (e.g. identical character face names) via relative GameAssets/ paths.
  • Sidecar Metadata: Tune 9-slice borders, UV wrap modes (auto-tiling), scale, and custom Pixels-Per-Unit (PPU) via companion JSON files.
  • Live Disk Hot-Reload: Modify textures in Photoshop or GIMP, hit save, and see changes in-game instantly with zero restarts.
01-UI-Themes • 05-Button-Prompts

2. GameObject & Layout

ObjectConfig.json

Manipulate Unity GameObjects, RectTransforms, and UI hierarchies at runtime without touching a single line of C# code.

  • Full Transform Control: Reposition, rotate, scale, resize, or hide (SetActive) any UI element or HUD canvas.
  • Hierarchy Path Suffix: Match unique transform paths (e.g. content_root/menu/main_menu) to resolve ambiguous objects.
  • NewImages Injection: Dynamically insert brand-new custom UI image components directly into existing screens.
  • Layout Customization: Scaled-down in-game menu (10% shrink), custom save slot highlight tints, and full-screen title backgrounds.
TitlescreenFullBG • MainMenuBg

3. Dialogue & Portrait

Portraits & Names

Breathes cinematic life into dialogue boxes with automatic speaker naming and dynamic portrait injection across all six titles.

  • Dynamic Portrait Injector: Inserts character facial portraits directly inside speech windows with custom offsets and padding.
  • Speaker Name Formatting: Auto-prepends speaker names with optional UPPERCASE, line breaks, and word-wrap limits.
  • Bubble Cleanup: Seamlessly hides the intrusive default speaker tag bubble while preserving game logic.
  • Menu Portrait Remapper: Custom main menu portrait mapping for FF2, FF4, and FF6 preserving native aspect ratios.
MenuPortraitMap.json • SpeakerNames

4. Font & Typography

fontconfig.json

Replaces default pixel remaster typefaces with any installed system-wide font per UI role and language.

  • Two-Phase Engine: Diagnostic font mapper traces internal Unity fonts, followed by clean custom font swapping.
  • Role-Based Scoping: Map distinct fonts for Main, Title, Battle, and Number elements independently.
  • Per-Language Granularity: Assign tailored fonts for English (En), Japanese (Ja), and other localizations.
  • Micro-Typography: Precise control over font size multipliers, line spacing (LineSpace), and vertical baseline offsets.
System/fontconfig.json

5. Text & Inline Icons

IconsConfig.json

Data-driven text replacement, re-translations, menu renaming, and rich-text inline iconography across all game screens.

  • Data-Driven Text Overrides: Swap text strings by localization database ID, exact string match, or Regex search-and-replace.
  • Hierarchy Text Target: Override specific screen headers or button labels by targeting their GameObject hierarchy.
  • Rich Text Inline Icons: Embed custom icon tags (e.g. <IC_BAG>, <IC_POTION>) directly into text lines.
  • Auto Atlas & Full Color: Automatically packs icons into texture atlases with disk caching and disables dimmed item tints.
TextConfig.json • Disk Atlas Cache

6. Logging & Utility

Diagnostics

Essential quality-of-life toggles, automated mod conflict detection, and deep inspection loggers for mod authors.

  • Texture Conflict Scanner: Scans active mods in 00-Mods/ at boot and alerts if two mods provide competing textures.
  • Mod Discovery: Clean console summary detailing all discovered mods, themes, and configuration assets.
  • Quality-of-Life Toggles: Disable the software mouse cursor, force VSync, and load high-performance DDS textures.
  • Granular Loggers: Specialized diagnostic channels for textures, battle sprites, fonts, dialogue keys, and UI hierarchies.

Directory Layout & 5-Layer Cascading Priority

KupoUI.PR roots all mod assets inside a single <GameRoot>/Modules/ directory created automatically upon your first game boot. Assets are categorized into structured subdirectories, with a clearly defined priority cascade: 

<GameRoot>/Modules/
  ├── .cache/                         ← Auto-generated texture atlas cache
  ├── 00-Mods/                        ← Active standalone mods
  │   ├── Amano Style TitleScreen/
  │   │   ├── ObjectConfig.json
  │   │   └── TitleLogoImage.png
  │   └── FF2 DFFOO Portraits/
  │       └── SpeakerPortraits/
  │           ├── SPEAKER_01.png      ← Firion
  │           ├── SPEAKER_02.png      ← Maria
  │           └── SPEAKER_03.png      ← Guy
  ├── 01-UI-Themes/                   ← Full UI theme packs (e.g. Darker UI)
  ├── 02-UI-Frames/                   ← Window frame texture packs
  ├── 03-UI-BgColor/                  ← Window background color variations
  ├── 04-UI-Cursors/                  ← Custom cursor and pointing hand sprites
  ├── 05-Button-Prompts/              ← Gamepad button glyphs (PS5, Xbox, Switch)
  └── System/                         ← Cross-game fonts & global configurations
      ├── fontconfig.json             ← Custom system font mapping
      ├── Icons/                      ← Custom inline rich text icons
      └── FF2/                        ← Game-specific rules (FF1–FF6)
          └── SpeakerPortraits/
              └── MenuPortraitMap.json ← Character menu portrait remapping

Lookup Priority Order (Highest to Lowest)

When an in-game sprite or texture is requested, KupoUI.PR resolves matches by filename (without extension) through the following pipeline:

  1. 05-Button-Prompts/<ButtonPromptsFolder> Highest Priority
  2. 04-UI-Cursors/<CursorsFolder>
  3. 03-UI-BgColor/<UIBgColorFolder>
  4. 02-UI-Frames/<UiFramesFolder>
  5. 01-UI-Themes/<UIThemesFolder>
  6. 00-Mods/ (Root mod folders)
  7. 00-Mods/<GameTag>/ (e.g. 00-Mods/FF2/)
  8. 00-Mods/System/
  9. <GameTag>/ (Root-level game-tag folder, if present)
  10. System/<GameTag>/ (e.g. System/FF2/)
  11. System/ (Cross-game global fallback, lowest priority)
Smart Blocking & Active Pack Scoping Need to temporarily disable a mod or asset folder without deleting it? Simply prefix the folder name with block (e.g. block-mod or block_portraits). KupoUI.PR's engine will ignore the directory entirely. Furthermore, category folders (01-UI-Themes through 05-Button-Prompts) only load JSON configs from the currently selected active pack, guaranteeing that inactive theme packs never leak unintended overrides.

Data-Driven Configuration Reference

Modding with KupoUI.PR requires zero compilation. Everything is declared in clean, human-readable JSON files:

ObjectConfig.json Runtime UI Transform & Text Styling

Reposition, scale, resize, hide, or alter font colors for any GameObject across menus and HUDs: 

{
  "objects": [
    {
      "TargetObjectName": "main_menu",
      "TargetPath": "RootObject/menu_canvas/ui_root/notch_root/title(Clone)/content_root/menu/main_menu",
      "Position": { "x": -730, "y": 580, "z": 0 },
      "Scale": { "x": 0.9, "y": 0.9, "z": 1.0 }
    },
    {
      "TargetObjectName": "last_text",
      "TargetPath": "RootObject/menu_canvas/ui_root/notch_root/title(Clone)/content_root/start/last_text",
      "FontSize": 40,
      "TextColorWhite": true,
      "DisableShadow": true
    }
  ]
}

fontconfig.json System-Wide Font Swapping

Replace default pixel fonts with your favorite system fonts, complete with custom line spacing and vertical baseline offsets: 

{
  "En": {
    "Font01": { "FontName": "Dissidia", "LineSpace": 0.90, "YOffset": 4 },
    "Font07": { "FontName": "Dissidia", "LineSpace": 0.90, "YOffset": 4 },
    "Font08": { "FontName": "pix Chicago", "FontSize": 26, "LineSpace": 1.2, "YOffset": 4 }
  }
}

TextConfig.json Targeted Re-Translations & Rich Text Icons

Modify in-game labels or dialogue lines directly by key or string, injecting custom icons seamlessly: 

{
  "Language": "En",
  "texts": {
    "MSG_SYSTEM_002": "<IC_BAG> Inventory",
    "Status": "Attributes",
    "Configuration": "Settings"
  }
}

Linux & Steam Deck Configuration

Because BepInEx utilizes a custom native winhttp.dll wrapper to inject itself into the game's Unity IL2CPP runtime, Valve's Proton compatibility layer will ignore it by default on Linux and Steam Deck. You must explicitly configure Proton to load the local version:

  1. Right-click your Final Fantasy Pixel Remaster game in your Steam Library and select Properties...
  2. In the General tab, locate the Launch Options input field at the bottom.
  3. Paste the following command line override:
export WINEDLLOVERRIDES="winhttp=n,b"; %command%

Quick Installation Steps:
  1. Install BepInEx IL2CPP 6.0-pre.2 (or newer) into your target Final Fantasy Pixel Remaster directory.
  2. Run the game once so BepInEx can generate the required interop assemblies in BepInEx/interop/.
  3. Drop KupoUI.PR.dll into <GameRoot>/BepInEx/plugins/.
  4. Boot the game. Your <GameRoot>/Modules/ directory and default configs will be generated automatically.
