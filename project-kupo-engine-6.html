Kupo Engine 6: Next-Gen FFVI Enhancement Engine.

Kupo Engine 6 (KupoEngine6, formerly KupoEngine / KupoHook) is an all-in-one enhancement engine, modern graphics pipeline, reverse-engineering framework, and in-game presentation suite built specifically for the legacy PC release of Final Fantasy VI (2015 Steam Release). Built via zero-modification DLL proxying (glew32.dll) from a complete 100% static and dynamic audit of all 772,705 lines across 6,144 decompiled functions in FF6.exe, it seamlessly modernizes rendering, unlocks true 32-column widescreen field and battle presentation, restores classic mechanics, eliminates input lag, and exposes extensive real-time modding and debugging tools.

Core Architectural Pillars

Kupo Engine 6 replaces legacy mobile port compromises with hardware-accelerated rendering, authentic console timing, and zero-repack modding pipelines:

1. DirectX 11 Bridge & CRT Shaders

Transfers OpenGL 2.x frames directly in VRAM to a modern Direct3D 11 flip-model swapchain (~0.02ms latency) with VRR, G-Sync, FreeSync, and Windows 11 Auto-HDR support.

  • Screen-Space Subpixel Anti-Shimmer: 5-tap luminance contrast reconstruction eliminates crawling tile edges during scrolling with zero 512×512 texture atlas bleed.
  • HLSL Color Grading & CRT Simulation: SNES Classic Warm CRT, Super Famicom 9300K Cool, Dark & Moody (World of Ruin Gothic), 240p/480p sinusoidal scanlines, RGB aperture grille triad mask, and barrel curvature.
  • AMD FSR 1.0 & Motion Smoothing: In-engine EASU spatial upscaling, RCAS sharpening, and temporal CRT phosphor persistence.
  • 10 PSX 3D Battle Transitions: Hardware Vortex, Ripple, Mirror Shatter, Falling Sand Melt, Horizontal Raster Shear, Diamond Iris, Radial Zoom, Wave, Curtain, and Roulette.

2. 32-Column True Widescreen

Expands field map tile generation from 16 to 32 columns (1024px native / 512px GBA) and +40 vertical rows via stack-safe multi-pass paging without stretching pixels.

  • Surgical Lateral Frustum Bypass: Patches AOT ARM simulation branch 0x1634F7 while preserving vertical slot-recycling branches to guarantee zero duplicated townspeople.
  • Symmetrical OAM 8-Bit Coordinate Expansion: Expands top headroom to 48px (0x30) and bottom vertex threshold to 0xD0 across all 4 recompiled sprite routines.
  • Sub-Room Entity Partitioning: Queries live ROM npcProperties (0x71D34C) in FUN_0044b110 to isolate composite interior rooms (e.g. Figaro Castle, Blackjack).
  • Mode 7 & Combat Widescreen: Edge-to-edge battle backdrops (Land000..055), Opening Snow March Mode 7 widescreen, and customizable Overworld Navimap HUD.

3. Composite HD Maps & Weather

Breaks free from restrictive 16×16 tile limits and 16-color palettes by liberating field rooms into full-scale, multi-layer high-definition composite artwork.

  • Live EWRAM & LZSS ROM Unpacker: Dumps active decompressed field layers or unpacks any of the 432 maps directly from the embedded GBA ROM with semantic collision mask PNGs.
  • Runtime Layer Replacer: Ingests loose HD layers from obb/maps/composite/{MapID}/ with subpixel camera-synchronized world-origin quads.
  • Sidecar JSON & FOV Compensation: Real-time X/Y pixel and UV offset tuning in composite.json with native tile suppression (SuppressVanillaTiles = 1).
  • Atmospheric Weather Engine: Procedural multi-layer falling snow with depth parallax and wind sway across Narshe maps.

4. 30-Slot Saves & Classic Battle HUD

Replaces clunky mobile menus with a 30-slot glassmorphic save manager and an authentic SNES-style "Tab - Left" native battle interface.

  • 30 Save Slots + Quicksave Continue: Hooks FUN_004a1000 to replace the 5-slot mobile screen with 3 paged tabs (Slots 1–30), Quicksave Continue banner, and Steam Cloud auto-import.
  • Virtual Staging Engine: Stages custom save files through native slot 0 buffers for 100% authentic deserialization with zero binary buffer overflows.
  • Classic Native Battle HUD: Enforces "Tab - Left" layout, injects native FreeType/FLB hero names above HP numbers, suppresses mobile bust portraits, and highlights active turns in yellow (#F8D800).
  • Triangle / Button Y Turn Switch: Binds active party turn cycling directly to Gamepad Triangle / Y with authentic audio chirps.

5. 60 FPS, FMV Cinema & Audio Suite

Unlocks fluid 60 FPS gameplay, hardware-accelerated boot/cutscene FMV playback with retro CRT post-processing, and polyphonic audio mixing.

  • 60 FPS & Fast-Forward (1.25x–10x): Live RAM delta-time patching across Field, Town, and Airship scenes with stutter-free F1 / R2 speed cycling.
  • In-Process FMV Cinema Player: Native Windows Media Foundation H.264/MP4 decoding (OPEN.mp4 boot autoplay) with dedicated PS1 240p/480i CRT scanlines, FSR 1.0, and frame interpolation.
  • Polyphonic Audio & Master Volume: Multi-voice polyphonic audio mixer, WASAPI master volume attenuation (0%..100%), restored menu cancel SFX (0x165), and loose sounds/*.wav replacement.
  • 600+ ID Sound Debugger: Live in-game SFX scanner and audition player.

6. VFS, Retranslation & ImGui Suite

Eliminates 700+ MB main.obb archive repacking and exposes real-time entity spawning, perceptual sprite hashing, script retranslation, and UI inspection.

  • 13-Language Script Dumper & Retranslator: Extracts all 8,838 strings across 13 languages to JSON/TXT and hot-reloads custom translations via FUN_00548a00 with zero byte-length limits.
  • Live NPC Spawner & Variant Cycling: Instant EWRAM slot 4..31 NPC injection with 120+ sprite archetypes, viewport tile picking, and dormant Square Enix NPC sprite sheet cycling.
  • pHash Visual Object Inspector: Click-to-Pick any on-screen sprite, monster, or UI quad using 64-bit dHash/aHash Hamming distance search and 1-click PNG template export.
  • Unity-Style FLB Object Explorer: Live hierarchy inspector and Numpad 2 asset package dumper for all 455 game UI layouts.

Reverse Engineering Methodology & Technical Marvel

The creation of Kupo Engine 6 and its surgical fixes for decades-old engine limitations were driven by exhaustive static decompilation paired with live binary telemetry:

NSA Ghidra: 772,705 Lines / 6,144 Functions

Complete 100% static audit of the 17.6 MB Win32 PE executable (FF6.exe), mapping how the Ahead-Of-Time (AOT) statically recompiled Japanese GBA ROM (BZ6J) bridges emulated EWRAM (0x02000000), IWRAM (0x03000000), VRAM (0x06000000), and OAM (0x07000000) into host memory.

REA Telemetry: AOT Frustum & Slot Preservation

Pinpointed the 5 upstream field simulation branches in the recompiled ARM core (0x1634F7..0x163BE8), diagnosing why prior community attempts to disable NPC culling corrupted entity slot recycling and spawned duplicate townspeople.

8-Bit Wraparound OAM Vertex Math

Uncovered the 8-bit unsigned wraparound arithmetic (sub ecx, 0x100) inside host OpenGL vertex decoders (FUN_0044b190, FUN_00452330, FUN_00433d30), symmetrically balancing vertical thresholds to eliminate top and bottom sprite popping under expanded FOV.
