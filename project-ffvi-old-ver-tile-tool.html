FFVI Old Tile Tool: Map BIN Section & Tile Architecture.

FFVI Old Tile Tool (ffvi_tileConverter) is a dedicated desktop application for viewing, exporting, importing, and managing section graphics and indexed tiles stored inside Final Fantasy VI (Old Ver.) map .bin files. Built upon Maki's original FFVI Tile Tool, this modernized release resolves critical Section 1 reinsertion bugs, eliminates manual hex-editing friction, and introduces a comprehensive suite of quality-of-life workflow enhancements.

Key Breakthrough: Reliable Section 1 Reinsertion

This build finally fixes the reinsertion of Section 1 (formerly called Chunk 1) directly into map .bin files—cutting a significant amount of build time and eliminating the human error of manual hex editing. In previous versions of the legacy tool, re-injecting Chunk 1 would corrupt or garble the binary file.

Fixed Reinsertion

Section 1 & Section 2

Cleanly exports and re-imports both Section 1 (fixed 512x512 region) and Section 2 (variable-height 512-wide region) without corrupting map headers or offsets.

Smart Palettes

Mirrored Palette Sync

Automatically detects mirrored palette repetitions stored inside each .bin file and synchronizes all repeated blocks during image import.

Batch Pipeline

Mass Export & Import

Process entire folders of map binaries in seconds with PNG/BMP format selection, progress tracking, cancellation support, and summary logs.

Strict Indexed Color Workflow & Engine Limitation:

While reinsertion is now seamless, the underlying game executable still enforces a strict index order for colors. You cannot arbitrarily shuffle or reorder the color table in Photoshop and expect it to render properly—if the original index arrangement is not preserved, the in-game output breaks (appearing similar to a film negative).

Note: Bypassing this engine-level palette indexing restriction entirely would require a custom runtime texture injection layer (similar to Special K). For standard .bin editing, always use an index-preserving pixel editor such as Aseprite, MtPaint, or carefully locked indexed palettes in Photoshop.

File Format, Data Layout & Import Rules

Each Final Fantasy VI (Old Ver.) map .bin file contains two distinct indexed image data regions paired with BGRA-like section palettes (using inverted alpha byte behavior):

Section 1 Import Rules

Front Fixed Region (512×512)

  • Accepted Formats: .png or .bmp
  • Color Depth: Must be 8-bit indexed
  • Dimensions: Must be exactly 512 × 512 pixels (fixed-size region at the front of the BIN)
Section 2 Import Rules

End Variable Region (512×H)

  • Accepted Formats: .png or .bmp
  • Color Depth: Must be 8-bit indexed
  • Width: Must be exactly 512 pixels wide
  • Height: Variable height according to the specific map's section data usage near the end of the BIN
Recommended Editors

Pixel & Palette Tools

  • Aseprite: Ideal for strict 8-bit indexed palette editing and pixel art workflows.
  • MtPaint: Lightweight indexed bitmap editor with exact palette slot control.
  • Adobe Photoshop: Supported when exporting in Indexed Color mode without reordering the color table.
