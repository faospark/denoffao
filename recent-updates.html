Quick Update Suikoden I & II HD Remaster

Recent Updates: BepInEx Conversions & Save Editor v2.0

A quick heads-up on my recent Suikoden I & II HD Remaster updates: Kraken Patch, Open Paths Mod, and True Matilda Glitch Restoration have now been converted into BepInEx plugins (no more replacing game bundle files), and the Bright Shield Save Editor now has a native Windows desktop build.

Mods Converted to BepInEx Plugins

BepInEx Plugin Nexus #14

True Matilda Glitch Restoration

Converted into a BepInEx plugin! The border gate visual is now synced with the hitbox, so you can actually recreate and see yourself pushing the gate/wall just like on the original PS1 (or configure it to just stay open).

Download on Nexus Mods (#14) →
BepInEx Plugin Nexus #18

Kraken Patch

Now a standalone BepInEx plugin with early Chuchara recruitment at the HQ Docks (once Viki and Badeaux join), giving you the full Kraken family (Chuchara, Abizboah, and Rulodia) while saving your Listening Crystals for Feather and Siegfried.

Download on Nexus Mods (#18) →
BepInEx Plugin Nexus #17

Open Paths Mod

Converted to a BepInEx plugin! Automatically clears the Tinto Mines shortcut rocks, solves the Cave of the Wind boulder puzzle, and now also unlocks the Forest Village Armor Shop door early.

Download on Nexus Mods (#17) →

Bright Shield Save Editor v2.0.0 (Native Rust)

The Suikoden II Save Editor has been updated to Bright Shield Save Editor v2.0.0 — a fast, standalone Native Rust Windows desktop app (BrightShield.exe) featuring an auto-scanned Saves tab with portraits, automatic .bak & full .zip backup snapshots, a restore diff viewer, 8 languages, custom themes, Tessai's Hammers, and S1 transfer editing. The Tauri and Web versions remain available at v1.4.14.
